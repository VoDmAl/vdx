# Решение: build vs adopt

Статус: **предложение** по итогам web-research 2026-05-22. Ждёт подтверждения
пользователя — после чего предложенные решения P-D3…P-D6 из
[decisions.md](decisions.md) станут D3+.

## Что оседлать (готовое, не писать своё)

| Задача | Инструмент | Роль |
|--------|-----------|------|
| Раннер P1 | **mise** | Запуск задач, полиглот, JSON-discovery. `vdx <verb>` → `mise run <verb>` |
| Fallback-раннер | нативные `make` / `composer` / `npm` | Если `mise.toml` ещё нет |
| Сбор security-фактов | **OpenSSF Scorecard** | `--probes` → JSON |
| Сбор code-quality фактов | **Qlty CLI** | Локально, 40+ языков, без аккаунта |
| Запуск линтеров | **MegaLinter** | 50 языков, один прогон |
| Scaffold-fix на своих | **copier** | `copier update`, 3-way merge |
| Транспорт для агента | **MCP** | Перечисление и вызов команд |
| Человекочитаемая проекция | **AGENTS.md** | vdx генерирует секцию `## Commands` |

## Что строит сам vdx (защищаемое ядро — нет ни у кого)

1. **Нормализованный словарь глаголов** `up/down/build/test/check/fix` поверх mise
   + детект стека + генератор `mise.toml`.
2. **Версионируемая рубрика + drift-движок** — сравнение проекта с текущей версией
   рубрики. Архитектура «probes → JSON-факты → policy-движок» (взята из Scorecard).
3. **Shared-infra оркестрация** — `vdx up` поднимает зависимости-инфраструктуру
   (Global Traefik и т.п.) до запуска проекта. Ни один раннер не моделирует.
4. **Структурированный исполняемый манифест** для агента — vs проза auto-memory.

## Упаковка для Claude Code

Плагин, бандлящий три слоя:
- **MCP-сервер** — 6 глаголов как инструменты + `list_capabilities`. Путь
  «действовать мгновенно».
- **skill** — когда читать манифест; workflow discover-and-record при его отсутствии.
- **hook** — детерминированная фиксация проверенного success path в манифест.

## Критерии решения (выполнены)

- Минимум нового кода — оседлать готовое: ✅ раннер, сбор фактов, scaffold, транспорт.
- Кроссстековость: ✅ mise + Qlty + MegaLinter полиглотны.
- Машиночитаемость: ✅ MCP + `mise tasks --json`.
- Догфудинг: vdx сам соответствует рубрике на L4.
